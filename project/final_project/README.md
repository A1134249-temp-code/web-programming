##測試帳號與系統重置說明
為了方便助教快速評分，且避免測試期間核心資料（如主要 Admin 帳號）Email、密碼被修改且遺忘，故提供此帳號做環境的重製使用：

* **測試入口帳號：** `testAdmin`
* **測試入口密碼：** `testAdminPassword123`

> **此帳號功能：** 
> 登入後系統會建議直接執行初始化，將資料庫還原至預設狀態並建置可用於操作之 admin。若操作用 admin 帳號資料遺失，使用此帳號登入即可進行重置。

---

##核心功能與快速操作指南

登入一般帳號後，建議可以優先測試以下核心功能（詳細架構可以參考期末簡報）：

1. 一鍵系統重置與初始化： 使用專屬的 testAdmin 帳號登入，可執行全站業務資料清空，系統將自動引導建立新的初代 Admin 帳號，提供乾淨無髒資料的測試環境。
2. 問題追蹤生命週期與自動化通知： 使用 Member/PM 帳號提報 Bug 後，切換至該專案的 PM 帳號進行審核與狀態變更（如駁回或標記已解決）。操作後可檢查 Bug 提報帳號左上角的站內通知。
3. Google Charts 生成： 進入首頁儀表板，可直接瀏覽由系統底層動態撈取、渲染的資訊 (根據使用者呈現的圖表種類可能不同)。
4. Excel 報表匯出： 進入 Admin 的系統管理頁面，或 PM 的 PM 管理頁面，點擊匯出相關按鈕，測試系統生成的 Excel 報表下載。
5. 帳號維護與備援機制： 在登出狀態下測試「忘記密碼」的 Email 驗證重設流程；或於登入後進入個人資料頁面，測試需輸入舊密碼驗證的安全修改機制。
